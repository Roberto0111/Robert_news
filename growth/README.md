# Roberto News Growth

The existing 20:00 carousel remains the complete daily news post.

The 21:15 growth pipeline:

1. Reads recent Instagram Insights when permission is available.
2. Builds a 1080x1920, 15-second Reel from the verified daily cards.
3. Adds an original professional newsroom soundtrack.
4. Publishes the video to the repository and then Instagram.
5. Writes a date-specific success marker only after publishing succeeds.

The first frame contains the lead story and is also used as the feed cover. The
renderer never crops the original 1080x1350 cards.
